Rotate Array by One

Given an array arr[], rotate the array by one position in clock-wise direction.

Examples:

Input: arr[] = [1, 2, 3, 4, 5]
Output: [5, 1, 2, 3, 4]
Explanation: If we rotate [1, 2, 3, 4, 5] by one position, the last element 5 goes to the front.
