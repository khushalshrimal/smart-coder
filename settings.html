Important Security & Quota Information

  • Client-Side Storage: An API key stored in a Chrome extension client is not a server-side secret. Do not use an enterprise master key; use a dedicated Gemini key with restricted access.
  • Quota & Billing Notice: A successful "Test Connection" verifies valid authentication and model endpoint availability. It does not imply unlimited free requests. Free-tier requests are subject to Google AI Studio's RPM (requests per minute) and TPM (tokens per minute) rate limits.
  • Permitted Practice: This extension is intended strictly for permitted self-study and practice environments where external AI assistance is allowed.
